# Lynn 桌宠挂件

Claude Code 桌宠挂件——卡通小猫常驻桌面，实时反映本机 Claude Code session 状态，任务完成弹系统通知带结果摘要，点击可与自己 spawn 的 Claude Code 会话流式对话。

## v1.1 特性

- **气泡历史**：应用生命周期内持久——关窗（× 或 Esc）重开不丢，且关窗不断会话（进程存活，重开接着聊）；重启应用后清空
- **三套聊天主题**：贴纸 C（默认）/ 漫画 A（含打字点动画）/ 极简 B
- **透明度滑杆**：窗体背景透明度 0.3–1.0（默认 0.92）
- **设置持久化**：主题与透明度存于 `~/.lynn-widget/settings.json`

## 构建与运行

前置：node ≥ 20、rust（含 cargo）。

```bash
npm install
npm run tauri dev     # 开发运行
npm run tauri build   # 打包
```

> 本仓库自带 `src-tauri/.cargo/config.toml`，将 crates.io 指向 rsproxy.cn 镜像（原因：镜像区域网络，直连不稳）。如需还原官方源，删除该文件即可。

## 人工验收清单

1. **启动**：操作——`npm run tauri dev` 启动应用。预期——桌面出现透明小猫（192×208 置顶窗），播 idle 呼吸动画，可拖动。
2. **状态联动**：操作——另开终端跑一个 Claude Code 任务。预期——猫切 working 动画。
3. **完成通知**：操作——等该任务跑完。预期——猫播 done（弹跳星光）+ 系统通知「任务完成 · 项目名（用时）」带结果摘要，气泡摘要行同样带项目名与用时。（macOS 未签名 dev 构建可能收不到通知，已知限制。）
4. **唤起对话**：操作——点击猫。预期——wave 挥爪 + 头顶弹出深色气泡窗。
5. **流式对话**：操作——气泡输入文字回车。预期——流式回复逐字上屏。观察点：窗口已开时再点猫只聚焦不重连（活进程复用）。
6. **退出干净**：操作——完全退出应用后执行 `pgrep -fl claude`。预期——无该应用残留的子进程。
7. **气泡历史**：操作——点猫开气泡 → 说两轮 → 点 × 或 Esc 关 → 再点猫重开。预期——历史还在，且「会话已连接」只有一行（不随开关窗累积）；会话未断，可接着聊。（重启应用后清空属预期，A 档语义。）
8. **主题与透明度**：操作——点 ⚙ → 切三主题与拖透明度滑杆。预期——即时生效；关掉气泡重开 → 设置保持（存于 `~/.lynn-widget/settings.json`）。
9. **纯工具回合**：操作——让 Lynn 跑一个纯工具回合（如「运行 ls 看看当前目录」）。预期——气泡有输出且有分隔线。

> 回归项：连点猫不刷「会话已连接」；× 关闭正常；theme-a 下发送有打字点动画；日志有 stderr 落盘。

## 已知限制

- macOS 未签名 dev 构建通知可能不弹（既有）；首次触发通知时 macOS 可能弹系统授权框，点「允许」即可
- 气泡窗失焦即关（light-dismiss）：点击窗外任意位置（桌面/其他应用/拖动猫）或 Cmd-Tab 切走应用都会关闭气泡——机制上无法区分失焦原因；会话进程保活不受影响，点猫即可重新打开
- 气泡进程常驻：关窗不结束 Claude 会话，应用完全退出才收殓（ExitRequested 钩子统一 chat_stop）
- 聊天历史不跨应用重启（A 档设计）
