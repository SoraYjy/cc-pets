# Lynn 桌宠挂件

Claude Code 桌宠挂件——卡通小猫常驻桌面，实时反映本机 Claude Code session 状态，任务完成弹系统通知带结果摘要，点击可与自己 spawn 的 Claude Code 会话流式对话。

## v1.1 特性

- **气泡历史**：应用生命周期内持久——关窗（× 或 Esc）重开不丢，且关窗不断会话（进程存活，重开接着聊）；重启应用后清空
- **三套聊天主题**：贴纸 C（默认）/ 漫画 A（含打字点动画）/ 极简 B
- **透明度滑杆**：窗体背景透明度 0.3–1.0（默认 0.92）
- **猫大小调节**：⚙ 面板「大小」滑杆 0.5–1.5（默认 1.0）——运行时即时缩放，贴地长大/缩小、水平居中不漂；点击穿透始终贴合猫体
- **设置持久化**：主题与透明度存于 `~/.lynn-widget/settings.json`

## v1.2 特性

- **链接外开**：回复中的链接点击后用系统浏览器打开（后端仅放行 http/https）
- **精灵动画 CPU 优化**：样式仅在帧变化时写入、窗体隐藏时暂停动画循环；启动 60s 后 debug.log 每 60s 打点一次 `sprite style writes` 写入计数供自检
- **通知点击聚焦**：任务完成通知点击后 60s 内气泡自动弹出并显示结果摘要（启发式——以「应用被激活」近似「点了通知」，见已知限制）
- **多会话视图**：右键猫呼出会话面板——本机全部运行中的 Claude Code 会话一行一个（项目 / 会话名 / 状态点 / 相对活跃时间），busy 绿点呼吸提示、idle 灰点，按状态（busy 在前）+ 项目名排序；数据 2s 一拍（watcher 快照），相对时间面板内每秒刷新；× / Esc / 点击面板外任意区域均可收起（light-dismiss，纯展示无输入）
- **立绘多皮肤**：`pet.json` skins 映射多套立绘，⚙ 设置面板芯片切换（petSkin 持久化）；导入管线 `--skin <id>` 指定皮肤槽、`--compose-rows` 按行条图拼接精灵图

## 构建与运行

前置：node ≥ 20、rust（含 cargo）。

```bash
npm install
npm run tauri dev     # 开发运行
npm run tauri build   # 打包
```

> 本仓库自带 `src-tauri/.cargo/config.toml`，将 crates.io 指向 rsproxy.cn 镜像（原因：镜像区域网络，直连不稳）。如需还原官方源，删除该文件即可。

## 人工验收清单

1. **启动**：操作——`npm run tauri dev` 启动应用。预期——桌面出现透明小猫（288×312 置顶窗，含缩放余量；精灵本体仍 192×208 逻辑尺寸），播 idle 呼吸动画，可拖动。
2. **状态联动**：操作——另开终端跑一个 Claude Code 任务。预期——猫切 working 动画。
3. **完成通知**：操作——等该任务跑完。预期——猫播 done（弹跳星光）+ 系统通知「任务完成 · 项目名（用时）」带结果摘要，气泡摘要行同样带项目名与用时；点击该通知（应用被激活）会在 60s 内自动弹出气泡显示摘要（启发式，见已知限制）。（macOS 未签名 dev 构建可能收不到通知，已知限制。）
4. **唤起对话**：操作——点击猫。预期——wave 挥爪 + 头顶弹出深色气泡窗。
5. **流式对话**：操作——气泡输入文字回车。预期——流式回复逐字上屏。观察点：窗口已开时再点猫只聚焦不重连（活进程复用）。
6. **退出干净**：操作——完全退出应用后执行 `pgrep -fl claude`。预期——无该应用残留的子进程。
7. **气泡历史**：操作——点猫开气泡 → 说两轮 → 点 × 或 Esc 关 → 再点猫重开。预期——历史还在，且「会话已连接」只有一行（不随开关窗累积）；会话未断，可接着聊。（重启应用后清空属预期，A 档语义。）
8. **主题与透明度**：操作——点 ⚙ → 切三主题与拖透明度滑杆。预期——即时生效；收起气泡再点猫恢复 → 设置保持（存于 `~/.lynn-widget/settings.json`）。
8b. **猫大小**：操作——点 ⚙ → 拖「大小」滑杆（0.5–1.5）。预期——猫实时缩放（贴地长大/缩小、水平居中不漂），拖到 0.5 明显小只、1.5 明显大只；点击穿透在任意缩放下仍贴合猫体轮廓；重启应用后保持。
9. **纯工具回合**：操作——让 Lynn 跑一个纯工具回合（如「运行 ls 看看当前目录」）。预期——气泡有输出且有分隔线。
10. **清屏与重开**：操作——⚙ 面板点「清屏（保留会话）」→ 气泡清空并显示「已清屏（会话保留）」，继续对话 Lynn 仍记得上下文；点「重开会话」→ 按钮变「确认重开？（将丢失当前对话记忆）」再点执行（3 秒不点回弹）→ 气泡清空显示「已重开会话」，新会话从头开始。
11. **链接外开**：操作——让回复包含一个网页链接并点击它。预期——系统默认浏览器打开该链接，气泡窗自身不导航（仍是气泡界面）。
12. **空闲 CPU**：操作——任务完成后（猫 idle）让应用运行满几分钟，执行 `grep "sprite style writes" ~/Library/Logs/lynn-widget/debug.log | tail -3`。预期——idle 档写入计数 ≈180/60s（3fps 猫），不得为数千级（窗体隐藏时接近 0）。
13. **通知点击弹气泡**：操作——任务完成通知弹出后点击该通知（应用被激活）。预期——60s 内气泡自动弹出并显示结果摘要（启发式，见已知限制；macOS 未签名 dev 构建可能收不到通知）。
14. **多会话面板**：操作——右键猫。预期——面板列出其它运行中的 Claude Code 窗口（项目 / 状态 / 活跃时间）；在其中某窗口跑任务 → 该行状态点实时变绿（busy 呼吸）；点击面板外任意区域或再右键猫 → 面板收起（点猫重开）。
15. **皮肤切换**：操作——点 ⚙ 查看皮肤芯片。预期——现有像素猫单皮肤下芯片渲染正确、点选后 petSkin 持久化（存 `~/.lynn-widget/settings.json`）；双皮肤切换验收待官方图导入后补。

> 回归项：连点猫不刷「会话已连接」；× 关闭正常；theme-a 下发送有打字点动画；日志有 stderr 落盘。

## 测试与回归

回归网分三层，各守一段：

- **L1 格式化 golden**（`src/format.test.ts`）：`src/format.ts` 纯函数（时长/摘要行/项目名/通知截断）的金字表用例——验收轮修过的摘要切分、时长格式化、cwd 解析都有钉子
- **L2 渲染 golden**（`src/markdown.test.ts`，jsdom）：`renderMarkdown`（marked + DOMPurify）的关键结构渲染 + XSS 攻击样本剥除——innerHTML 白名单防线
- **L3 watcher 场景**（`src-tauri/src/watcher.rs` 测试模块）：多 session 聚合与 staleness 间隙续读的事件序列 golden——通知丢失类 bug 的回归钉

```bash
npm test        # 前端（vitest）
npm run test:rust   # 后端（cargo test）
npm run test:all    # 全量
```

纪律：验收修复的 bug 必须在对应层留回归钉（golden 用例），不是只改代码。

## 已知限制

- macOS 未签名 dev 构建通知可能不弹（既有）；首次触发通知时 macOS 可能弹系统授权框，点「允许」即可
- 通知点击聚焦是启发式（v1.2）：桌面端插件拿不到通知的原生点击事件，以「发通知后 60s 内应用被激活（pet 窗获得焦点）」近似「点了通知」——因此 60s 窗口内 Cmd-Tab 切走再切回、Dock 点击等任何激活都会弹气泡；60s 后或该通知的气泡已显示过则不弹。未来插件支持原生点击事件时可升级为精确触发
- 气泡窗失焦即收（light-dismiss）：点击窗外任意位置（桌面/其他应用/拖动猫）或 Cmd-Tab 切走应用都会收起气泡——机制上无法区分失焦原因；会话进程保活不受影响，点猫瞬时恢复（hide/show 生命周期，DOM 与历史原样保留）
- 气泡窗隐藏常驻：×/失焦是 hide 而非销毁，隐藏态 webview 常驻内存约 +30-60MiB；应用生命周期内首次创建仍有整页加载延迟（dev 下较明显，打包后显著变快），此后点猫瞬时出现
- 气泡进程常驻：收起不结束 Claude 会话，应用完全退出才收殓（ExitRequested 钩子统一 chat_stop）
- 聊天历史不跨应用重启（A 档设计）
- 会话存活检测（unix）以 kill(pid,0) 为唯一主信号：Claude Code busy 期间心跳冻结不再导致会话从面板/working 消失；代价是若系统因权限（EPERM）误判，该会话会瞬时消失（macOS 同用户场景近乎不可达），理论上极端 pid 回绕可能短暂出现幻影条目
- 皮肤芯片列表在 chat 窗加载时读取一次（v1.2）：chat 窗是 hide/show 生命周期、重开气泡不重载 webview，导入新皮肤后需重启应用新芯片才出现
- 皮肤导入要求与默认皮肤同网格规格（8×4、4/8/4/4 帧布局），不同规格的图会被导入质检拒绝（详见 docs/ART.md）

## 换形象

按 docs/ART.md 的规格生成网格图后，执行 `python3 -I scripts/import_generated_sheet.py` 导入（详见 docs/ART.md）。
