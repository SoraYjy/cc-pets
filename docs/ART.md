# Lynn 桌宠美术资产规范（ART）

本文档约定 widget 桌宠的美术资产格式、Lynn 官方形象生成 prompt，以及从官方图到正式 spritesheet 的制作注意事项。

## 一、格式契约

### 1. Spritesheet 规格

沿用 Codex Pets 的规格，具体如下：

- **网格**：8 列横向网格，一行对应一个动画状态。
- **单元格**：每格 192×208 像素（cellWidth = 192，cellHeight = 208）。
- **排列**：第 1 行放第 1 个动画状态，第 2 行放第 2 个动画状态，依此类推；每个状态内的帧从该行左起第 1 格开始连续排列。
- **文件格式**：PNG，带 alpha 通道。
- **背景**：完全透明，不绘制底色、不留白边。

### 2. pet.json 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 宠物唯一标识，如 `lynn`。 |
| `displayName` | string | 展示名称，界面上显示用。 |
| `spriteVersionNumber` | number | spritesheet 版本号，图片内容变更时递增，用于缓存失效。 |
| `spritesheetPath` | string | spritesheet 图片路径，如 `assets/pet/spritesheet.png`。 |
| `cellWidth` | number | 单元格宽度，固定 192。 |
| `cellHeight` | number | 单元格高度，固定 208。 |
| `columns` | number | 网格列数，固定 8。 |
| `animations` | object | 动画表，键为状态名，值见下。 |

`animations` 中每个动画条目的字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `name` | string | 动画状态名，如 `idle`。 |
| `row` | number | 该状态在 spritesheet 中占用的行号（从 0 开始计数）。 |
| `frames` | number | 该状态的帧数，从该行第 1 格起连续占用。 |
| `fps` | number | 播放帧率（帧每秒）。 |
| `loop` | boolean | 是否循环播放；`false` 表示单次播完（播完停留末帧）。 |

### 3. 首版动画表

| 状态 | row | frames | fps | loop | 说明 |
| --- | --- | --- | --- | --- | --- |
| `idle` | 0 | 4 | 3 | 是 | 待机呼吸循环。 |
| `working` | 1 | 8 | 6 | 是 | 工作中循环。 |
| `done` | 2 | 4 | 4 | 否 | 完成，单次播完。 |
| `wave` | 3 | 4 | 5 | 否 | 打招呼，单次播完。 |

## 三、生成正式立绘的注意事项

1. **官方图 = 定妆照**。按第二节 prompt 生成的官方图是 Lynn 的「定妆照」，用来确立人设外观：配色、发型、猫耳、发卡、异色瞳、制服等细节均以此为准。
2. **转 spritesheet 需按第一节规格产出逐帧图**。定妆照不能直接当 spritesheet 用；正式制作时需依据定稿形象绘制逐帧动画图，严格满足：每个状态独占一行、每格 192×208、8 列网格、PNG 带 alpha、背景透明。绘制时注意**帧间只动该动的部位**（例如 idle 只做呼吸与猫耳微动、wave 只动手臂），其余部位逐像素保持不动，避免整体抖动。
3. **占位版与正式版替换**。当前 `assets/pet/spritesheet.png` 是正式版，由 `scripts/import_generated_sheet.py` 从大模型生成的猫猫网格图（源图 `/Users/sora/Downloads/test-cat.jpg`）导入生成；勿重跑 `scripts/render_placeholder_pet.py`，它会把 spritesheet 覆盖回银灰卡通小猫占位版。只要正式版的动画状态与帧数和第一节首版动画表一致，`pet.json` 的 `animations` 无需改动；若有增删状态或调整帧数，再同步更新 `pet.json` 并递增 `spriteVersionNumber`。
